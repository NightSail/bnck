bnck(1)

bnck maps executable names to the projects and distribution packages that provide them.

lookup data project

lookup

Search for a command to find its projects and packages, or search for a project to list its commands. Matches use full or partial executable names and project IDs; package names are not searched.

Project pages show package coverage across channels. Executable pages show every project that provides the exact name. Package links open the current channel pages.

bnck does not install, build, or execute packages, and the dataset does not include package versions, platform support, or installation instructions.

data

The dataset is built from Debian, Fedora, Arch Linux, Homebrew, crates.io, npm, and PyPI metadata, then resolved through curated project mappings.

Coverage is limited to accepted records in each release. A missing command or package may still be available, and channel counts do not describe the full contents of a channel.
